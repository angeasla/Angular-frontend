# Ωράριο Εργασίας

Το ωράριο εργασίας καθορίζει τις ώρες που υποχρεούσαι να παρέχεις εργασία.
Η ελληνική νομοθεσία θέτει ανώτατα όρια — **τα αφεντικά δεν μπορούν να τα
αγνοούν**, ανεξάρτητα από τι λέει η «εσωτερική πολιτική» της επιχείρησης.

## Νόμιμο ωράριο

- **40 ώρες/εβδομάδα** (5-ήμερη ή 6-ήμερη εβδομάδα)
- Μέγιστο **8 ώρες/ημέρα** (5-ήμερη) ή **6,67 ώρες/ημέρα** (6-ήμερη)
- Ελάχιστη ημερήσια ανάπαυση: **11 συνεχόμενες ώρες**
- Εβδομαδιαία ανάπαυση: **35 συνεχόμενες ώρες** (συμπεριλαμβανομένης της Κυριακής)

## Θέματα ωραρίου

- **[[Ώρες Εργασίας]]** — λεπτομέρειες για τα νόμιμα όρια και τα διαλείμματα
- **[[Υπερωρίες]]** — εργασία πέρα από το νόμιμο ωράριο και οι αμοιβές
- **[[Νυχτερινή Εργασία]]** — επίδομα για εργασία 22:00–06:00
- **[[Εργασία 6ης Ημέρας]]** — δικαιώματα για εργασία Σαββάτου
